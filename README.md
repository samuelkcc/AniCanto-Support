# AniCanto Support

[繁體中文](http://anicanto.com/support.html?lang=zh-HK) · [English](http://anicanto.com/support.html?lang=en) · [简体中文](http://anicanto.com/support.html?lang=zh-Hans) · [日本語](http://anicanto.com/support.html?lang=ja)

Use this public repository for iPad, iPhone, macOS, Windows, and website support.
Please use the [technical issue form](https://github.com/samuelkcc/anicanto-support/issues/new?template=technical-issue.yml).
You can write in English, 繁體中文, 简体中文, or 日本語.

Reports are public. Do not post private videos, recordings, scripts, account details, receipts, or complete logs.

- [Support guide](http://anicanto.com/support.html)
- [iPad privacy policy](http://anicanto.com/privacy.html)
- [AniCanto website](http://anicanto.com/)
- [Earlier desktop reports](https://github.com/samuelkcc/AniCanto/issues)

The iPad and iPhone editions are in development. Follow the website for release announcements.
This repository contains support information and forms. Application source and website source are stored separately.
