# AniCanto-Support

[繁體中文](http://anicanto.com/support.html?lang=zh-HK) · [English](http://anicanto.com/support.html?lang=en) · [简体中文](http://anicanto.com/support.html?lang=zh-Hans) · [日本語](http://anicanto.com/support.html?lang=ja)

Public technical support for **AniCanto on iPad and iPhone only**. Both editions are in development.
Use the [mobile technical issue form](https://github.com/samuelkcc/AniCanto-Support/issues/new?template=technical-issue.yml).
You can write in English, 繁體中文, 简体中文, or 日本語.

Reports are public. Do not post private videos, recordings, scripts, account details, receipts, or complete logs.

- [iPad and iPhone support guide](http://anicanto.com/support.html)
- [iPad privacy policy](http://anicanto.com/privacy.html)
- [AniCanto website](http://anicanto.com/)

**macOS and Windows:** Use the [desktop project's own support page](https://github.com/samuelkcc/AniCanto/blob/main/SUPPORT.md) and [desktop issues](https://github.com/samuelkcc/AniCanto/issues).

This repository contains public support information and forms. It does not contain application or website source.
